# Siegen Student Jobs Guide

A responsive single-page web guide for students looking for part-time, seasonal, hospitality, and online work opportunities in Siegen.

## Purpose

The site organizes useful job-search information into a simple, mobile-friendly interface so students can quickly discover relevant categories and external resources.

## Features

- Responsive single-page layout
- Clear job-category navigation
- Sections for restaurants, bars/clubs, seasonal work, and online/remote opportunities
- Direct links to external resources
- Custom CSS styling and responsive design

## Technology

- HTML5
- CSS3
- Responsive web design
- External web links

## Project Structure

```text
index.html
```

## Running Locally

No build system is required.

Open `index.html` directly in a browser, or serve the directory with a simple local HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
